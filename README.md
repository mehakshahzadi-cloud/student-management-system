# Student Management System

## Overview
A console-based Student Management System developed in C++ for the Programming Fundamentals course. The system manages student records, calculates academic results, and stores data using file handling.

## Features
- Add Student Records
- Search Students by ID
- Update Student Information
- Delete Student Records
- Display All Students
- Display Topper Students
- Generate Student Reports
- Calculate GPA, Percentage, and Grades
- Class Pass/Fail Ratio
- Save and Load Data from File
- Input Validation
- Support for Multiple Class Sections

## Technologies Used
- C++
- Functions
- Structures
- Arrays
- Loops
- Conditional Statements
- File Handling
- Input Validation

## Learning Outcomes
- Programming Fundamentals
- Structured Programming
- Data Management
- File Handling
- Problem Solving
- Modular Programming
