# student-management-system
## Overview
A console-based Student Management System developed in C++ for the Programming Fundamentals course.

## Features
- Add Student
- Search Student
- Update Student
- Delete Student
- Display All Students
- Display Topper Students
- Generate Student Reports
- Class Pass/Fail Ratio
- Save and Load Data using File Handling

## Technologies
- C++
- Arrays
- Structures
- Functions
- File Handling
